# 800 · Decisions — POINTER

> ⚠️ **Nodo pointer, non owner.** Le decisioni (ADR) sono di proprietà di
> [.sinapsi/decisions.md](../../.sinapsi/decisions.md) — un solo log, append-only.
> **Non creare qui ADR paralleli:** sarebbe una seconda fonte di verità (drift).

Il log canonico delle decisioni → [.sinapsi/decisions.md](../../.sinapsi/decisions.md).
Le decisioni grandi e irreversibili → [.sinapsi/adr/](../../.sinapsi/adr/).
Il processo per decidere → [.sinapsi/rfc/](../../.sinapsi/rfc/).

**Perché questo nodo esiste comunque:** per intercettare l'istinto "creo ADR strategici nel brain".
Le decisioni *strategiche* (prodotto/mercato) sono comunque decisioni: vanno nello **stesso** log,
con lo stesso formato, linkando il nodo brain rilevante. Un log, non due.
